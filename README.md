# CSA5111_CNS
This repo contains all CNS subject related lab programs and etc..

## Running a C program

Open the `.c` file you want to run. Install the recommended **C/C++ Compile Run**
and **C/C++** extensions when prompted to get the editor's run button. You can
also run the built-in **Run active C program** task from **Terminal: Run Task**;
it builds the active file with GCC and runs it in the integrated terminal.
